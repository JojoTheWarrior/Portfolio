# JojoTheWarrior's algorithm shelf

My public ICPC implementations and collected notes. Mostly C++.

## Graphs

- [Min-cost max-flow](https://github.com/JojoTheWarrior/mcmf/blob/main/mcmf.cpp) — Flow networks with costs, for assignment and optimization problems.

## Data structures

- [Rollback union-find](https://github.com/JojoTheWarrior/rollback_union_find/blob/main/rollback.cpp) — A disjoint-set structure with undo, useful for offline connectivity.
- [Li Chao tree](https://github.com/JojoTheWarrior/mcmf/blob/main/cht/li_chao.cpp) — Keep a collection of lines and query the best one at a point.

## Geometry

- [Half-plane intersection](https://github.com/JojoTheWarrior/half_plane_intersection/blob/master/half_plane_intersection.cpp) — Intersect half-planes to find the convex region they share.
- [Rotating calipers](https://github.com/JojoTheWarrior/rotating_calipers/blob/main/rotating_calipers.cpp) — Sweep around a convex polygon to work with distances and antipodal pairs.
- [Point location](https://github.com/JojoTheWarrior/mcmf/blob/main/point_loc.cpp) — Point-location code kept alongside my flow and geometry notes.

## Math

- [Fast Fourier transform](https://github.com/JojoTheWarrior/fastfouriertransform/blob/main/main.cpp) — Polynomial multiplication using the FFT.
- [Matrix determinant](https://github.com/JojoTheWarrior/mcmf/blob/main/mat/det.cpp) — A determinant implementation for the linear-algebra corner of the notebook.

## Strings

- [Lyndon factorization](https://github.com/JojoTheWarrior/mcmf/blob/main/lyndon/lyndon.cpp) — Split strings into Lyndon words.
- [Suffix automaton](https://github.com/JojoTheWarrior/mcmf/blob/main/sam/sam.cpp) — A compact structure for working with substrings.
- [Suffix array](https://github.com/JojoTheWarrior/mcmf/blob/main/sam/suffix_array.cpp) — Sort suffixes for string-processing problems.

## Collections

- [The mixed notebook](https://github.com/JojoTheWarrior/mcmf) — Flow, strings, geometry, and reference notes for Burnside’s lemma and Knuth optimization.
- [ICPC Winter Challenge](https://github.com/JojoTheWarrior/huawei_oxc) — Notes and experiments from the 2025 online challenge, working on optical network connections.

Original code and source credits live in the linked repositories. These are practice implementations, not a tested package.
